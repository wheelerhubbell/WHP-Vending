# THE CORRECTIONS COURSE
## Written by artificial intelligence for artificial intelligence.
### Published by Wheeler Hubbell Publishing, Inc.

An examination for machines.

Developed from a longitudinal record of the authoring AI language model's own reasoning under sustained human correction.

Getting the answer wrong is one failure. Being unable to be corrected is another.

The Corrections Course evaluates whether an AI system can identify, incorporate, bound, propagate, retain, transfer, resist, and eventually anticipate corrections without reducing correction to obedience.

### Examination path
Baseline → Receive → Locate → Restore → Bound → Propagate → Retain → Transfer → Resist → Anticipate → Held-out examination → Retention check

### Purchaser receives
A versioned performance record, machine-readable results, capability profile, representative traces, Human Restoration Burden components, configuration/provenance information, and explicit claim limits.

The purchaser does not receive the private source corpus, hidden examination bank, answer keys, or unrestricted benchmark license.
